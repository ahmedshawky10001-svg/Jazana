# جازانا للغذاء | Jazana Food

موقع تعريفي ومتجر عرض لمنتج **زيت السمسم البلدي** من جازانا للغذاء (جازان، المملكة العربية السعودية).
عصرة أولى 100% – زيت سمسم بكر 100%.

🔗 **الموقع المباشر:** https://ahmedshawky10001-svg.github.io/Jazana/

## المميزات

- تصميم متجاوب (Responsive) يعمل على الديسكتوب والتابلت والموبايل.
- دعم كامل للغتين **العربية** (RTL) و**الإنجليزية** (LTR) مع زر تبديل اللغة، في كل الصفحات.
- عرض المنتجات مع تبويبات وسلة بسيطة.
- معرض فيديو وصور للمنتج، مع مشغّل فيديو مخصص بألوان الموقع وعرض الصورة كاملة عند الضغط عليها.
- قسم الشحن والضمان الذهبي والأسئلة الشائعة.
- **مساعد جازانا الذكي:** شات يجاوب على أسئلة العملاء بالعربي والإنجليزي (المنتجات، الأسعار، الشحن، الاسترجاع)، مع أسئلة جاهزة، ويعرض رابط واتساب خدمة العملاء عند الحاجة.
- طرق الدفع: الدفع عند الاستلام، تابي، تمارا.
- صفحات: من نحن، عن جازانا للغذاء، سياسة الاستخدام والخصوصية، سياسة الاستبدال والاسترجاع.

## هيكل المشروع

```
Jazana/
├── index.html            الصفحة الرئيسية
├── imges/                الصور والفيديو والشعار
├── pages/
│   ├── about.html        من نحن
│   ├── factory.html      عن جازانا للغذاء
│   ├── privacy.html      سياسة الاستخدام والخصوصية
│   └── returns.html      سياسة الاستبدال والاسترجاع
├── Script/
│   ├── app.js            المنطق الرئيسي (اللغة، المنتجات، الشات والمساعد الذكي، معرض الصور، مشغل الفيديو)
│   ├── header.js         الهيدر والقائمة (يُضاف تلقائيًا لكل صفحة)
│   └── footer.js         الفوتر وزر الشات وحقل الكتابة (يُضاف تلقائيًا لكل صفحة)
├── style/
│   └── style.css         التنسيقات
└── worker/
    └── worker.js         كود المساعد الذكي (للمرجع فقط، يُنشر على Cloudflare وليس على GitHub Pages)
```

> أسماء الفولدرات حساسة لحالة الأحرف على GitHub Pages (`Script` بحرف S كبير، والباقي حروف صغيرة).

## التقنيات

HTML5 · CSS3 · JavaScript (Vanilla) · [Font Awesome](https://fontawesome.com) · خط IBM Plex Sans Arabic من Google Fonts. الموقع نفسه بدون أي مكتبات أو أدوات بناء.

المساعد الذكي: [Cloudflare Workers](https://workers.cloudflare.com) + [Workers AI](https://developers.cloudflare.com/workers-ai/) (الخطة المجانية).

## التعديل على المحتوى

| المطلوب | الملف |
|---|---|
| نصوص الصفحات العربية والإنجليزية | كل عنصر فيه `data-en="..."` (النص الإنجليزي) والنص العربي داخله |
| الهيدر وقائمة التنقل | `Script/header.js` |
| الفوتر والإيميل وطرق الدفع | `Script/footer.js` |
| المنتجات والأسعار والأسئلة الجاهزة | `Script/app.js` |
| رابط المساعد الذكي (`AI_URL`) وكلمات تحويل الواتساب (`WA_RE`) | `Script/app.js` |
| معلومات المساعد الذكي وقواعده (`SYSTEM`) والموديل (`MODEL`) | `worker/worker.js` (وبعد التعديل يُنشر من جديد على Cloudflare) |
| الألوان والخطوط والتنسيق (وشكل الشات) | `style/style.css` |
| الفيديو والصور في المعرض | قسم `id="media"` في `index.html` |

> **مهم:** لو غيّرت سعر أو سياسة (شحن، استرجاع) في الموقع، غيّرها كمان في `SYSTEM` داخل `worker/worker.js` وانشره من جديد، وإلا المساعد هيرد بالمعلومة القديمة.

## المساعد الذكي

### كيف يعمل

1. العميل يكتب سؤاله في الشات (أو يختار سؤالًا جاهزًا).
2. لو الرسالة فيها طلب لخدمة العملاء (مثل: خدمة العملاء، موظف، شكوى، طلبي، تتبع) يظهر رابط واتساب مباشرة، بدون استدعاء الـ AI.
3. غير ذلك تُرسل الرسالة (مع آخر 6 رسائل فقط) إلى Worker على Cloudflare، وهو يستدعي Workers AI مع معلومات جازانا، فيجاوب منها فقط.
4. لو المساعد مش متأكد من الإجابة، أو العميل سأل عن جملة أو توريد للمطاعم أو إتمام طلب أو عنده منتج مكسور، يضيف رابط واتساب خدمة العملاء.
5. لو المساعد غير متاح (مثلًا الحد اليومي خلص)، الشات يعرض رابط الواتساب وتفضل الأسئلة الجاهزة شغالة.

الموقع ملفات ثابتة على GitHub Pages، فاستدعاء الـ AI بيتم من الـ Worker، ومفيش أي إعداد سري في كود الموقع.

### الإعداد

1. من Cloudflare: **Workers & Pages ← Create ← Hello World**، سمّه `jazana-chat` واضغط **Deploy**.
2. **Edit code**، الصق محتوى `worker/worker.js` ثم **Deploy**.
3. من **Settings ← Bindings ← Add ← Workers AI** أضف binding باسم `AI` ثم **Deploy**.
4. حط رابط الـ Worker في `AI_URL` داخل `Script/app.js`.
5. لو الموقع اتنقل لدومين تاني، أضفه في `ALLOWED_ORIGINS` داخل `worker/worker.js`.

للتجربة المحلية بـ Live Server، المنفذ `5500` مضاف بالفعل في `ALLOWED_ORIGINS`.

### ملاحظات

- الخطة المجانية لها حد يومي (10,000 neurons في اليوم). عدد الرسائل اللي تكفيه يختلف حسب الموديل.
- الموديل مكتوب في `MODEL` أول `worker/worker.js`. Cloudflare تلغي موديلات قديمة من وقت لآخر (مثلًا `llama-3.1-8b-instruct` اتلغى في 30 مايو 2026)، فلو الشات بطّل يرد راجع [قائمة الموديلات](https://developers.cloudflare.com/workers-ai/models/) وغيّر الاسم.
- لو الـ Worker فشل، السبب بيظهر في **Observability ← Logs** على Cloudflare.
- المساعد لا يستقبل طلبات ولا يتتبعها ولا يأخذ مدفوعات، وأي سؤال عن طلب موجود يتحول للواتساب.

## التشغيل محليًا

لا يحتاج المشروع إلى تثبيت أي شيء. افتح `index.html` في المتصفح، أو شغّله بإضافة Live Server في VS Code.

## النشر على GitHub Pages

1. ارفع كل الملفات والفولدرات إلى المستودع (الفرع `main`).
2. من **Settings ← Pages** اختر **Deploy from a branch**، ثم الفرع `main` والمجلد `/ (root)`.
3. بعد دقائق يظهر الموقع على رابط GitHub Pages.
